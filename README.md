# GameLobby - Premium Gaming Platform

A full-stack gaming platform with Swedish-inspired design.

## Tech Stack
- Next.js 14, TypeScript, Tailwind CSS
- Node.js, GraphQL, Apollo Server

## Features
- 🎮 Game library with categories
- ⭐ Featured games
- 🔍 Search with debounce
- 🇸🇪 Swedish-inspired design

## Setup
```bash
npm install
cd frontend && npm install
cd ../backend && npm install
cd backend && npm run dev
cd frontend && npm run dev
